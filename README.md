# 🚆 Dashboard de Sinalização Ferroviária

Projeto desenvolvido para o Curso de Ciência de Dados, utilizando Python e Streamlit.

## Objetivo

Criar um dashboard para analisar dados de sinalização ferroviária e comparar os sistemas **Bloco Fixo** e **CBTC**.

## Análises realizadas

O dashboard apresenta:

- Indicadores gerais do dataset;
- Comparação do headway entre Bloco Fixo e CBTC;
- Distribuição dos aspectos dos sinais (Verde, Amarelo e Vermelho);
- Relação entre velocidade permitida e tempo de ocupação do circuito.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly
- Streamlit

## Como executar

Instale as dependências:

```bash
pip install -r requirements.txt
```
